# 破壁人（POBIREN）

- 技术知识库：<https://pobiren.top/>
- 用户面板：<https://app.pobiren.top/>

本站是破壁人的技术知识库，不是售卖页。只写三类内容：线路类型之间的机制差别（IEPL / IPLC / 普通中转）、IP 属性会带来什么后果（住宅 IP 与机房 IP）、以及按业务场景怎么搭出口结构（多账号、直播上行、远程办公）。不放套餐价格、不做效果承诺、不写「最快最稳」这类无法核对的形容词。

## 内容是怎么核实、怎么改的

网络接入的结论容易过期：一条线路的表现会随上游调整而变，客户端版本升级可能改掉配置写法。所以：

- **能复现才写**：判断要么来自日常组网运行，要么来自工单里反复复现的问题，不写听来的说法；
- **带前提条件**：只写「什么场景下成立」，延迟、抖动、上行带宽绑定地区与时段；
- **标注核实时间**：文章更新时间体现在页面与站点地图里；
- **过期就改或删**：线路结构调整后相关段落直接改写，不做旧内容继续挂着的处理。
