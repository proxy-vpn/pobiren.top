## 一、先校准预期：GitHub 仓库在 SEO 里的真实作用

讨论「外链权重」之前先把机制讲清楚，避免把力气用错地方。

- GitHub 对 README、Profile、Issue、PR、Wiki、Gist 中的用户生成链接统一注入 `rel="nofollow"`，由 GitHub 的 HTML sanitizer 处理，仓库设置无法关闭。2026 年 11 月的两项独立核查再次确认这一点；`github.com` 域名权重虽高（DA≈92），但**不向本站传递 PageRank**。
- 因此：**在 README 放 `https://pobiren.top/` 不会直接涨权重**。指望「建仓库 = 涨排名」是误解。
- 本仓库真正的价值在于 **E-E-A-T 身份层**：
  1. 一个 stranger 可在 60 秒内确认「这个域名背后有真实、持续维护的技术团队」——账号创建时间、公开仓库列表、跨月的提交记录；
  2. 仓库里的方法论、配置示例、更新日志可被开发者引用，带来**自然外链**（这才是 dofollow 的来源）；
  3. 与站点 `/about/` 页互相印证（站点 → GitHub，GitHub → 站点），形成可验证的闭环；站点侧可用结构化数据 `sameAs` 指向本仓库。
- 结论：本仓库是**信任资产 + 可被引用的内容资产**，不是外链生成器。真正的外链增长靠第三节的渠道组合。

### 2.4 ⚠️ 重复内容风险（与 kuaifei.top）

`pobiren.top` 与 `kuaifei.top` 当前首页、指南、场景页**文案几乎逐字相同**。搜索引擎会判定为重复内容，两站争夺同一批词，结果往往是两个都掉出前列。

处理方案（按优先级）：
1. **不要**在两站发布同一篇指南原文。按受众改写：本站偏「团队 / 合规 / 专线原理」，快飞偏「快速上手 / 操作演示 / 档位选择」。
2. 确需保留的相同技术说明，选一站作为权威来源，另一站改为摘要 + 链接（或加 `rel="canonical"` 指向权威页）。
3. 每篇至少替换 40% 的例句、案例、截图与数据，确保独立价值。
4. 品牌词各自独立优化，不要互相引用对方品牌词做锚文本。

## 三、外链与权重建设（核心）

### 3.1 站群内链矩阵（唯一完全可控的 dofollow 来源）

- 三站 footer 互链已配置（`feixingti.top` / `kuaifei.top` / `tkya.us.ci`）。
- **补强方向**：在指南正文里做上下文内链，而不是只靠 footer。例如在「IEPL 与 IPLC 区别」正文中，自然地链接到 `/solutions/ecommerce-multi-account/` 说明选型落地。
- 锚文本用品牌名或主题描述（如「跨境电商多账号组网」），不要用「点击这里」。
- 评测站 `tkya.us.ci` 以「深度合作品牌」披露形式链接到本站——**保持披露透明**，避免被判为付费链接。

### 3.2 真实外链渠道（按投入产出排序）

| 渠道 | 链接属性 | 预期 | 具体做法 |
|---|---|---|---|
| 上下游合作方（机房 / 软路由厂商 / 跨境服务商） | dofollow | **高** | 互换「推荐资源」链接，放在对方官网资源页 |
| 技术社区（V2EX / 掘金 / 少数派） | UGC / 部分 dofollow | 中 | 发「IEPL/IPLC 原理长文」，结尾自然提及本站指南 |
| 行业目录 / 服务商数据库 | dofollow | 中 | 提交公司资料，保持 NAP（名称/地址/电话）一致 |
| GitHub Awesome 清单 / 资源仓库 | nofollow 但高曝光 | 中 | 提 PR 收录本站技术指南（真实有用才会被合并） |
| 问答平台（知乎等） | nofollow | 引流 | 回答问题并给出来源链接，不堆关键词 |
| 行业媒体 / 新闻稿 | dofollow | 高 | 产品更新、行业观察类稿件 |

### 3.3 可被引用的内容资产（linkable assets）

外链不是求来的，是别人引用你的东西时自然产生的。优先做这四类：

1. **线路测速方法论 + 公开样本数据**（晚高峰 RTT/抖动/丢包样本），可被引用为数据源；
2. **多账号 IP 隔离配置清单**（可下载 PDF / Markdown），实用型资源；
3. **客户端配置示例仓库**（开源，可 fork），与 GitHub 身份层联动；
4. **术语表 / 选型决策树**（IEPL / IPLC / BGP / 住宅 IP 一页讲清），易被百科与博客引用。

### 3.4 白帽红线

- 不买链接、不参与 PBN、不互刷 star；
- 不在 README 堆砌关键词；
- 不做 doorway pages / 桥页 / 隐藏文本；
- 外链增长保持自然节奏，避免短期暴增触发审计。

## 六、度量与 KPI

- **工具**：Google Search Console（主）、Bing Webmaster Tools、百度资源平台、站点日志分析。
- **核心指标**：非品牌词展现量 / 点击量、目标词平均排名、引荐域名数、索引覆盖率。
- **目标（12 个月）**：非品牌自然流量 +50%；30% 目标词进 Top 3；技术健康 ≥90 分；引荐域名稳步增长。
- **节奏**：每周记录排名与外链，每月复盘一次；至少积累 8 周数据才判断趋势。
